## 1.0.0

* 🎉 Initial release of MayR Local Notifications
* ✅ Zero-configuration setup - just call `init()` and go!
* 📱 Cross-platform support for Android, iOS, and macOS
* 🔔 Send immediate notifications with `send()`
* ⏰ Schedule notifications for specific times with `schedule()`
* 🚫 Cancel all pending notifications with `cancelAll()`
* 🔐 Automatic permission handling on all platforms
* 📝 Comprehensive documentation and example app
* 🐛 Debug logging support for troubleshooting
